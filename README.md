# MORPH-V — anonymous review artifact

Minimal implementation and frozen-record reproduction for **MORPH-V: Autonomous Growth of Reusable Observation Programs for Long-Video Reasoning**.

Start with [for_review/README.md](for_review/README.md) for installation, commands, expected outputs, and the exact scope of reproduction.

The artifact provides the executable typed registry and compiler, answer-independent structural verification, persistent library updates and reload, the original open-composition model replies and structural contexts, and the recorded predictions needed to recompute the library-growth results. The default reproduction is offline. It does **not** rerun model inference or regenerate perception features from videos.
